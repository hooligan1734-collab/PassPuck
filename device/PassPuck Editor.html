PassPuck Editor

Пароли и названия профилей устройства. Работает без интернета, данные никуда не отправляются.

№Название на экранеПарольСгенерировать
  • Этот редактор лежит прямо на устройстве. Откройте диск: на устройстве SETTINGS → Edit mode (или подключите его с зажатой кнопкой «Назад»), затем дважды кликните PassPuck Editor.html на диске CIRCUITPY.
  • В окне выбора папки выберите сам диск CIRCUITPY и разрешите браузеру изменять файлы.
  • Нужен браузер Microsoft Edge или Google Chrome: только они умеют сохранять прямо на диск.
  • Можно: латиница, цифры, символы английской клавиатуры, русские буквы. Для русских букв в Windows должны быть настроены Ctrl+Shift+1 (английский) и Ctrl+Shift+2 (русский).
  • После сохранения подождите 10 секунд, прежде чем отключать устройство (или SETTINGS → Exit edit mode после паузы).
  • Перед сохранением прежняя версия файла копируется в passwords.bak.
